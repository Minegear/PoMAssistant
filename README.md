# PoMAssistant

Application web d'aide pour **Pokémon Masters EX** : suivi des duos (sync pairs) et de leur investissement, gestion des ressources, et vue d'ensemble d'une arène (équipe de joueurs), le tout dans une seule interface.

> Projet de fan, non officiel. Pokémon et Pokémon Masters EX sont des marques de leurs propriétaires respectifs (Nintendo, Creatures Inc., GAME FREAK inc., DeNA). Ce projet n'est ni affilié ni approuvé par eux.

## Fonctionnalités

- **Hub** : événements et bannières en cours (avec compte à rebours) et liens utiles.
- **Catalogue** : liste de tous les duos.
- **Tracker** : niveau d'investissement et rôle EX des duos.
- **Ressources** : compteurs personnels de ressources.
- **Duos de l'arène / Ressources de l'arène** : ce que possèdent les membres de votre arène.

## Stack

[Vue 3](https://vuejs.org/) · [Vite](https://vite.dev/) · [Pinia](https://pinia.vuejs.org/) · [Vue Router](https://router.vuejs.org/) · [Supabase](https://supabase.com/) (base de données Postgres + authentification des admins)
